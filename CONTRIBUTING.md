# Contributing

Assieme is a work in progress, and things change quickly.

**Bug reports and ideas are welcome.** Please [open an issue](https://github.com/MoatCast/assieme/issues) that says what
you did, what you expected, what happened, and which versions of macOS, Claude Code and Codex you use. Remove anything
private from logs and screenshots first.

**Code contributions aren't being accepted yet.** Please don't open a pull request for now; this will be revisited as
the project matures. Forking is welcome under the [Apache-2.0 licence](LICENSE).

Security problems have their own route: see [SECURITY.md](SECURITY.md).
